# راهنمای ساخت و چک‌لیست انتشار نیچ مارکت

این سند دروازه‌های انتشار را مشخص می‌کند؛ تکمیل کد یا ساخت debug به‌معنای تأیید انتشار نیست. بازار هدف فعلی مایکت است و پرداخت کافه‌بازار یا Google Play در این اپ پیاده‌سازی نشده است.

## ابزار و اجرای محلی

JDK 17، Android SDK شامل API 35 و Build Tools مناسب، و دستگاه یا شبیه‌ساز API 24 به بالا لازم است. پروژه را در Android Studio باز کنید و با اینترنت وابستگی‌های Gradle را دریافت کنید:

```bash
python3 tools/validate_questions.py
python3 -m unittest discover -s tests -v
./gradlew assembleDebug assembleDebugAndroidTest
./gradlew connectedDebugAndroidTest   # پس از اتصال گوشی/شبیه‌ساز
```

APK آزمایشی در `app/build/outputs/apk/debug/` است. تست شبیه‌ساز CI برای اجرای دستی workflow فعال است. تست‌های instrumentation جای تست کامل رابط، عملکرد یا پرداخت واقعی را نمی‌گیرند.

## ساخت انتشار

از **کلید امضای نسخه قبلی** استفاده کنید؛ ساخت کلید جدید باعث ناسازگاری به‌روزرسانی می‌شود. کلید خصوصی و رمزها را در سورس یا چت قرار ندهید. متغیرهای `SIGNING_KEYSTORE_PATH`، `SIGNING_STORE_PASSWORD`، `SIGNING_KEY_ALIAS`، `SIGNING_KEY_PASSWORD` و `MYKET_PUBLIC_KEY` را از محیط امن تنظیم کنید، سپس:

```bash
./gradlew assembleRelease bundleRelease
# APK: app/build/outputs/apk/release/
# AAB: app/build/outputs/bundle/release/
apksigner verify --verbose --print-certs app/build/outputs/apk/release/*.apk
jarsigner -verify -verbose -certs app/build/outputs/bundle/release/*.aab
```

`apksigner` در Android SDK Build Tools و `jarsigner` در JDK است. صحت امضا و اثرانگشت را با نسخه منتشرشده تطبیق دهید. نبود کلید امضا یا کلید عمومی مایکت، فایل تجاری معتبر نمی‌سازد. CI یک پیش‌بررسی **بدون امضای تولید و بدون کلید مایکت** انجام می‌دهد؛ خروجی آن برای انتشار نیست. ساخت امضاشده CI فقط با secrets تنظیم‌شده انجام می‌شود. خودداری از نصب نسخه debug روی نسخه اصلی با امضای متفاوت؛ حذف برنامه اطلاعات محلی را پاک می‌کند.

## گیت‌های ضروری پیش از انتشار

- [ ] محتوای ۵۰۳ سؤال و توضیح‌ها، به‌ویژه حقوقی و بانکی، توسط متخصص و با منابع به‌روز بازبینی شده است؛ validator فقط ساختار را تأیید می‌کند.
- [ ] قیمت و SKU هر چهار محصول با پنل مایکت برابر و محصولات غیرمصرفی هستند.
- [ ] روی دستگاه واقعی با نسخه Release و حساب آزمایشی مایکت: خرید موفق، لغو، خطا، خرید تکراری، بازیابی پس از نصب مجدد و حساب متفاوت آزمایش شده‌اند.
- [ ] رفتار بازپرداخت و نگهداری مجوز آفلاین به صاحب محصول توضیح و تأیید شده است؛ اتحاد محلی خریدها ابطال را خودکار حذف نمی‌کند.
- [ ] ارتقا از نسخه قبلی با همان کلید امضا و حفظ بوکمارک، کارنامه و آزمون ناتمام روی دستگاه واقعی آزمایش شده است.
- [ ] خاموشی فرایند، فضای ذخیره‌سازی کم، تاریخ/ساعت تغییر‌یافته، راه‌اندازی مجدد و پایان زمان آزمون آزمایش شده‌اند.
- [ ] RTL، تم روشن/تیره، فونت بزرگ، کاهش حرکت، اسکرین‌ریدر و صفحه کوچک تا تبلت به‌صورت دستی بررسی شده‌اند.
- [ ] startup، حافظه، باتری و فریم‌ریت روی دستگاه‌های هدف اندازه‌گیری و ثبت شده‌اند؛ هیچ تضمین ۶۰fps بدون اندازه‌گیری داده نمی‌شود.
- [ ] اطلاعات تماس، حریم خصوصی، حقوق محتوا و تصویر، توضیحات تمرینی بودن سؤال‌ها و الزامات روز پنل فروشگاه تأیید شده‌اند.

## دارایی‌های انتشار و کانال‌ها

برای پیش‌تولید، اسکرین‌شات واقعی بدون اطلاعات شخصی را به‌صورت PNG با رزولوشن کاری پیشنهادی 1080×1920 و ویدیوی واقعی MP4 در رزولوشن کاری 1920×1080 تهیه کنید؛ این اعداد **الزام رسمی پنل نیستند**. پیش از آپلود ابعاد، تعداد، نسبت تصویر و مشخصات به‌روز هر پنل را مستقلاً کنترل کنید. لوگوی رسمی و تصویر هدر فعلی در برنامه موجودند؛ تأیید مالکیت و مجوز با صاحب محصول است.

- **مایکت:** تنها مسیر خرید فعلی؛ پس از تأیید تمام گیت‌های بالا، محصول‌ها و امضا را با پنل تطبیق و عرضه کنید.
- **کافه‌بازار:** این نسخه SDK پولکی ندارد؛ ابتدا یکپارچه‌سازی مستقل، SKU، سیاست‌ها و تست واقعی لازم است. عرضه پولی فعلی را پشتیبانی‌شده تلقی نکنید.
- **Google Play:** پرداخت و سیاست‌های این کانال جداست؛ تا بررسی و پیاده‌سازی سازگار، انتشار تجاری آن آماده محسوب نمی‌شود.
